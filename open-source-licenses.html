4. Open-Source Subtitle & Timed-Text Engines

VIDZA Player supports universal subtitle formats using industry-standard open-source parsing and rasterization engines:

Media3 Timed-Text Framework (ExoPlayer Text Track Renderer)

Maintainer: Google LLC • License: Apache License 2.0

Provides synchronized timed-text decoding for .srt (SubRip), .vtt (WebVTT), .ttml (Timed Text Markup Language), CEA-608 and CEA-708 closed captions, and Matroska embedded soft subtitle streams with zero latency clock sync.

libass / SSA & ASS Advanced Subtitle Renderer

Maintainer: The libass Project • License: ISC / LGPL License

A portable subtitle renderer for the SubStation Alpha (.ssa) and Advanced SubStation Alpha (.ass) subtitle formats. Handles complex typography, custom vector graphics, karaoke timing, font glyph rasterization, and multi-layer styling.

Security-Hardened ZIP Subtitle Archive Extractor

Maintainer: SkeltoLabs Open Core • License: Apache License 2.0

Integrated client-side decompression utility providing Zip-Slip path traversal defense when unpacking zipped subtitle archives directly into isolated cache memory.
